# Chest X-ray MVP Baseline Benchmarks

## Goal
Establish a clear performance baseline for the `COVID19_XRay` dataset using DenseNet121.

## Expected Metrics
Based on established medical AI literature using DenseNet121 for Chest X-Ray classification:

- **Accuracy**: > 92%
- **Sensitivity (Recall)**: > 94% (Crucial for medical screening)
- **Specificity**: > 90%
- **ROC-AUC**: > 0.95

## Reference Papers
1. CheXNet: Radiologist-Level Pneumonia Detection on Chest X-Rays with Deep Learning (Rajpurkar et al., 2017)
2. COVID-19 Image Data Collection: Prospective Predictions Are the Future (Cohen et al., 2020)
